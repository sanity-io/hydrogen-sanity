# RRS001: A server-only entry was imported in browser code.

## Cause

A module that the browser bundle includes imports `react-router-sanity/server`, `/cache`, `/preview/route`, `/live/route` or `/csp`. The `browser` condition of these entries resolves to a module that throws, so a server token can never reach the browser.

## Fix

Move the import into a loader, an action, a middleware, or a file that ends in `.server.ts`. React Router removes those from the client bundle.
