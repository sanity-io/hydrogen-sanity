# RRS010: The Sanity middleware is not registered.

## Cause

A loader, an action or a middleware called `context.get(sanityContext)`, but no Sanity middleware ran before it.

## Fix

Add `export const middleware = [sanityMiddleware]` to `app/root.tsx`. On React Router 7, also set `future: {v8_middleware: true}` in `react-router.config.ts`. In a unit test, use `createTestSanityContext()` from `react-router-sanity/testing`.
